# Advanced To-Do List

A simple and clean To-Do List application built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks (All / Active / Completed)
- Data is saved in localStorage (stays after page refresh)

## Technologies Used

- HTML
- CSS
- JavaScript (DOM, Events, Event Delegation, localStorage)

## How to Use

1. Clone the repository or download the files
2. Open `index.html` in your browser
3. Start adding your tasks

## What I Learned

- DOM manipulation
- Event handling
- Event Delegation
- Working with arrays (`map`, `filter`, `forEach`)
- Saving data with `localStorage`
